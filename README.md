## 🧰 What I build

| Project | What it actually is |
| :-- | :-- |
| [**similarism**](https://github.com/GenzPx/similarism) | Authorized SQLi auditor + login brute-force tester in one dependency-free Python CLI (sqlmap × hydra blend). |
| [**SickHack**](https://github.com/GenzPx/SickHack) | Terminal-style web security testing toolkit for Android. Educational use only. |
| [**security-toolkit**](https://github.com/GenzPx/security-toolkit) | OSINT CLI toolkit — recon utilities glued into one binary. |
| [**GenManagers**](https://github.com/GenzPx/GenManagers) | Android file manager + APK tools (File Manager+ × MT Manager × LuckyPatcher vibes), Kotlin + Compose. |
| [**Mammoth-Panels**](https://github.com/GenzPx/Mammoth-Panels) | Pterodactyl-style local bot runner for Android — server tabs, file manager, process monitor, foreground service. |
| [**DOWNLOADER-UX**](https://github.com/GenzPx/DOWNLOADER-UX) | Universal file downloader + URL analyzer for Termux / Linux. |
| [**EduKids**](https://github.com/GenzPx/EduKids) | Learning app for kids — because someone had to. |
| [**Games**](https://github.com/GenzPx/Games) | Last-survival game experiments. Chaos with a game loop. |
| [**achievement-hunters**](https://github.com/GenzPx/achievement-hunters) | Hunting GitHub achievements the wrong way, on purpose. |
| [**badge-lab**](https://github.com/GenzPx/badge-lab) | Git practice playground + README badge experiments. |
